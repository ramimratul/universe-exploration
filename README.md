# Universe Exploration

A single-player space exploration game built with **Python and Pygame**, featuring an AI agent powered by **A* pathfinding**.

## Requirements

* Python 3
* Pygame 2.6.1

## Setup

Download the files and open your terminal.

Install the required dependency:

```bash
pip install -r requirements.txt
```

## Run

Start the game with:

```bash
python main.py
```
